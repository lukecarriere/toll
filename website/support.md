# Support

## Questions and bugs

Open an issue at `github.com/lukecarriere/toll/issues`. Please include what you ran, what you expected and what happened.

## Security problems

Don't open a public issue for a security problem. Follow `SECURITY.md` in the repository, which uses private vulnerability reporting at `github.com/lukecarriere/toll/security/advisories/new`.

## Docs

Start with the [Docs](/docs). The MCP server has its own [guide](/docs/mcp).
